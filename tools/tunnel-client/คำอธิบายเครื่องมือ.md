# เครื่องมือเชื่อมต่อ Tunnel

โฟลเดอร์นี้เป็นตำแหน่งมาตรฐานของ `tunnel-client` สำหรับโปรเจกต์นี้:

```text
E:\Remote-MCP-Server\tools\tunnel-client
```

เมื่อติดตั้งแล้วจะมีไฟล์หลักดังนี้:

- `tunnel-client.exe` โปรแกรมที่พร้อมใช้งาน
- `tunnel-client-<version>-windows-<architecture>.zip` ไฟล์ต้นฉบับที่ดาวน์โหลด
- `SHA256SUMS.txt` รายการค่าแฮชจากผู้เผยแพร่
- `VERSION.txt` รุ่นที่ติดตั้ง
- `SOURCE.txt` แหล่งดาวน์โหลดและค่าแฮชของไฟล์

ติดตั้งหรืออัปเดตเป็นรุ่นล่าสุดด้วยคำสั่ง:

```powershell
Set-Location E:\Remote-MCP-Server
.\scripts\tunnel\install-client.ps1
```

ตัวติดตั้งจะดาวน์โหลดจาก release ล่าสุดของ `openai/tunnel-client` และตรวจ SHA-256 ก่อนนำมาใช้งาน ไฟล์โปรแกรมและ ZIP ไม่ถูก commit เข้า Git เพราะเป็นไฟล์ไบนารีจากภายนอก แต่ตัวติดตั้งจะสร้างไฟล์เหล่านี้ให้อัตโนมัติบนเครื่องปลายทาง
